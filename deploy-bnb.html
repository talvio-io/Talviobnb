Deploy Talvio Pixel Relic (TALV) — BNB Chain

Talvio Pixel Relic NFT: 7,777 pixel relics on BNB Smart Chain (chain 56), gas BNB. First 777 mints free for Binance Agent ID holders (1 free per Agent ID), then 0.0015 BNB each, max 5 per wallet.

Rules locked in the contract after deploy:

  • MAX_SUPPLY 7,777; FREE_LIMIT 777 (first 777 tokens free; a mint straddling the boundary pays only for the tokens past it).
  • Free mint is gated by the Binance Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F (on-chain read, balanceOf > 0), 1 free per Agent ID (MAX_FREE_PER_WALLET 1). While the free supply lasts, only Agent ID holders can mint; after the first 777, paid mint is open to any personal wallet.
  • MAX_PER_WALLET 5 (free + paid combined).
  • Paid mint fee: 0.0015 BNB per token after the free 777. Fees are HELD in the contract — the owner collects them with the Withdraw step below (only the owner can withdraw). Network gas is separate and variable.
  • Personal wallets only (contract callers are rejected on-chain).
  • $TALV (7.77 trillion, 82% to LP) is a separate token plan and is NOT this contract — this contract mints only the NFT, no $TALV. The $TALV token contract will be made by the owner themselves.
  • tokenURI = baseURI + number + .json (meta files are N.json; the 7,777 images + metadata already exist locally, NOT hosted yet).
  • Mint is CLOSED by default — the owner opens it in step 4, only after baseURI is set.

Warning: this contract is unaudited. Try small amounts first. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.
