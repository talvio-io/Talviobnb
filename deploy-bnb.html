Talvio — Total Deploy Console (Owner)

Owner-only page for the whole Talvio launch on BNB Smart Chain (56): the Talvio Pixel Relic NFT (steps 02–03), the $TALV token (step 04), linking + funding the mint rewards (step 05), opening the mint (step 06), with live state + summary in step 07. Every step is signed by the owner wallet — nothing here runs by itself.

  • Contract: Talvio Pixel Relic (TALV), ERC-721, 7,777 supply. tokenURI = baseURI + number + .json.
  • Free mint: the first 777 are free, gated by the Binance Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F — that registry is a constant baked into the contract code (not a deploy input), 1 free per Agent ID. The free quota counts only free claims — paid mints never consume it.
  • Random draw: minted token IDs are drawn at random from the remaining pool of 7,777 — not in order — so a Legendary can land in any mint and nobody can snipe a specific Relic.
  • Paid mint: 0.0015 BNB per token, open to any personal wallet from the moment the mint opens — nobody waits for the free phase to finish. MAX_PER_WALLET 5 (free + paid combined). Personal wallets only — contract callers are rejected on-chain. Fees stay in the contract until the owner withdraws them (step 07).
  • Metadata is already hosted: all 7,777 images + metadata live in the GitHub repo talvio-io/Talviobnb (nft/images/ + nft/meta/) and every metadata image field is an absolute URL. The base URI is prefilled in step 03.
  • Mint is CLOSED by default — the owner opens it in step 06, only after the base URI is set (step 03) and the $TALV rewards are linked + funded (step 05).
  • $TALV rewards are paid inside the mint transaction itself — 48,888,800 TALV per free Relic and 488,888,000 TALV per paid Relic, straight to the minter’s wallet, out of the NFT contract’s own $TALV balance. If that balance ever runs short mid-mint the mint still succeeds: the remainder is recorded on-chain as owed and the holder pulls it with claimOwed() after a top-up. Full-sellout reward total: 3,460,202,597,600 TALV.
  • $TALV the token is deployed from step 04 of this same console: ERC-20 Talvio (TALV), fixed supply 7,770,000,000,000 (7.77 trillion, 18 decimals), the entire supply minted to the owner wallet in the deploy transaction. No mint, burn or tax functions exist — the supply can never change. Published split: 82% liquidity / 10% top inviters / 8% treasury (executed by the owner from their wallet; the PancakeSwap LP itself is created after the genesis funds are collected).

Warning: this contract is unaudited. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.

01 — Connect owner wallet

Connect the wallet that will own the Talvio Pixel Relic contract. The page switches it to BNB Smart Chain automatically. The connected wallet becomes owner at deployment: it can set the base URI, open/close the mint and withdraw the mint fees. No other wallet can do those things.

Not connected.

This page detects OKX first (window.okxwallet), then other wallets, and will ask to switch/add BNB Smart Chain (56).

02 — Deploy Talvio Pixel Relic

Deploys the NFT contract (ERC-721, Talvio Pixel Relic / TALV). The economics above are constants in the code and can never change. The only constructor argument is the base URI — deploy with it empty and set the real one in step 03, so the address is live before any URI is attached.

⚠️ The Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F is hardcoded in the contract and cannot be changed after deployment — it was verified against the compiled contract before this page was published.

Waiting for a wallet connection.

03 — Set the metadata base URI

Points tokenURI at the published metadata (baseURI + number + .json). The artwork and JSON for all 7,777 relics are already generated and pushed under nft/meta/ in the repo. Do this before opening the mint (step 06).

04 — Deploy the $TALV token

Deploys the ecosystem token: ERC-20 Talvio (TALV), fixed supply 7,770,000,000,000 TALV (7.77 trillion, 18 decimals). The entire supply is minted to your connected wallet inside the deploy transaction — there are no constructor arguments and nothing else to configure. After this, no one (including you) can ever mint, burn or tax TALV; the contract has no such functions.

The token is independent of the NFT — you can deploy it before or after the NFT.

05 — Link $TALV + fund the reward balance

The NFT contract pays every minter’s $TALV reward inside the mint transaction (48,888,800 per free Relic, 488,888,000 per paid Relic) out of its own $TALV balance. Two things must happen before you open the mint: (1) tell the NFT contract which token to pay in (setTalvToken), (2) transfer $TALV from your wallet into the NFT contract. You can top the balance up at any time — funding is staged, it does not have to cover the whole sellout at once.

The default 500,000,000,000 covers the first ±1,022 paid mints (or all 777 free claims plus ±950 paid). A full sellout needs 3,460,202,597,600 TALV in total. If the balance runs short mid-mint, minting never fails — the unpaid part is recorded as owed and holders pull it with claimOwed() after you top up.

06 — Open the mint

The mint starts closed. Open it only after the base URI is set (step 03), the $TALV token is linked and the reward balance is funded (step 05), and the metadata is live. Paid mint and the free Agent ID claim both go live together — paid mint does not wait for the free phase. Close is the emergency brake — it stops new mints; transfers keep working while closed.

Only the NFT owner can run this. Do it only after baseURI is set correctly.

07 — State, withdraw + summary

Live state of the Talvio Pixel Relic contract, straight from the chain. Mint fees accumulate in the contract — withdraw sends the whole balance to the owner wallet. Then copy the summary box and send it to Muse to wire the mint into the public site and verify the deployment.
