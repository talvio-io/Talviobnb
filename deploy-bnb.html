Talvio Pixel Relic — Deploy Console (Owner)

Owner-only page for the TalvioBNB NFT contract on BNB Smart Chain (56). Every step is signed by the owner wallet — nothing here runs by itself.

  • Contract: Talvio Pixel Relic (TALV), ERC-721, 7,777 supply. tokenURI = baseURI + number + .json.
  • Free mint: the first 777 are free, gated by the Binance Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F — that registry is a constant baked into the contract code (not a deploy input), 1 free per Agent ID. After the free 777, paid mint is open to any personal wallet.
  • Random draw: minted token IDs are drawn at random from the remaining pool of 7,777 — not in order — so a Legendary can land in any mint and nobody can snipe a specific Relic.
  • Paid mint: 0.0015 BNB per token. MAX_PER_WALLET 5 (free + paid combined). Personal wallets only — contract callers are rejected on-chain. Fees stay in the contract until the owner withdraws them (step 05).
  • Metadata is already hosted: all 7,777 images + metadata live in the GitHub repo talvio-io/Talviobnb (nft/images/ + nft/meta/) and every metadata image field is an absolute URL. The base URI is prefilled in step 03.
  • Mint is CLOSED by default — the owner opens it in step 04, only after the base URI is set.
  • $TALV the token (7.77 trillion, 82% to LP) is a separate plan and is NOT this contract — this contract mints only the NFT.

Warning: this contract is unaudited. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.

01 — Connect owner wallet

Connect the wallet that will own the Talvio Pixel Relic contract. The page switches it to BNB Smart Chain automatically. The connected wallet becomes owner at deployment: it can set the base URI, open/close the mint and withdraw the mint fees. No other wallet can do those things.

Not connected.

This page detects OKX first (window.okxwallet), then other wallets, and will ask to switch/add BNB Smart Chain (56).

02 — Deploy Talvio Pixel Relic

Deploys the NFT contract (ERC-721, Talvio Pixel Relic / TALV). The economics above are constants in the code and can never change. The only constructor argument is the base URI — deploy with it empty and set the real one in step 03, so the address is live before any URI is attached.

⚠️ The Agent ID registry 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F is hardcoded in the contract and cannot be changed after deployment — it was verified against the compiled contract before this page was published.

Waiting for a wallet connection.

03 — Set the metadata base URI

Points tokenURI at the published metadata (baseURI + number + .json). The artwork and JSON for all 7,777 relics are already generated and pushed under nft/meta/ in the repo. Do this before opening the mint (step 04).

04 — Open the mint

The mint starts closed. Open it only after the base URI is set (step 03) and the metadata is live. Close is the emergency brake — it stops new mints; transfers keep working while closed.

Only the NFT owner can run this. Do it only after baseURI is set correctly.

05 — State, withdraw + summary

Live state of the Talvio Pixel Relic contract, straight from the chain. Mint fees accumulate in the contract — withdraw sends the whole balance to the owner wallet. Then copy the summary box and send it to Muse to wire the mint into the public site and verify the deployment.
